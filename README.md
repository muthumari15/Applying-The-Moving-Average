# Applying-The-Moving-Average

This documentation covers three sessions on technical indicators applied to crypto charts in TradingView. It starts with applying the Simple Moving Average (SMA) on an Ethereum chart to visualize trend direction, followed by using the Relative Strength Index (RSI) on a Bitcoin chart to gauge momentum, and concludes with an indicator-based trade report where a long trade is executed on Bitcoin based on price being above the 50 SMA with a neutral RSI, resulting in a realized profit.
